# Chicken Tom

A silly 3D browser game. You are Tom, an obnoxious rooster loose in the town of Clucksworth. Poop on everything, solve cryptic newspaper classifieds, set off disasters and earn perks.

**Play:** https://froggiewins.github.io/Chicken-Tom/

Works with keyboard and mouse, touch, or a gamepad. There is no build step: it is a static site, with `index.html` as the whole game and three.js in `vendor/`.

## Controls

| Action | Keyboard and mouse | Gamepad |
|---|---|---|
| Run / sprint | WASD or arrows / Shift | Left stick (push fully to sprint) |
| Look | Mouse, or J L I K | Right stick |
| Jump, flap, glide | Space | A |
| Poop (hold for a mega drop) | Left click or E | X or RT |
| Peck | Right click or F | B |
| Crow | Q | Y |
| Grab / throw | G | LB |
| Flop | T | RB |
| Pause | Esc or P | Start |
| Next classified ad | N | Back |
| Back to the farm | R | |

## Publish with GitHub Pages

Repo **Settings → Pages → Build and deployment**: choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
